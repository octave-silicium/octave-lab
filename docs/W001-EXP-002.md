# W001-EXP-002 | Independent evaluation handoff
24/11/2026. G-M1 and G-M2 remain open. This protocol is not an independent validation.
1. An independent practitioner prepares cases and reference decisions, without access to model responses. Prefer authorized anonymized documents, or independently constructed synthetic documents clearly labelled as such. No supplier confidential data or payment instructions sent to external models without explicit approval. A second reviewer adjudicates discrepancies before freeze. Keep gold separate and private. Record case mix, exclusion criteria, rule version, source rights and a SHA-256 commitment to both files; a hash is not evidence of independence by itself.
2. Freeze the conventional baseline and model configurations before seeing the held-out cases. Export candidate-only packet with python -m pipeline.evaluation_packet --cases /private/cases.json --output /private/packet-new --seed 23. This is a local tool: only candidate fields; no gold input and no output of stratum. The prompt file plus manifest preserve order and hash. Inspect before sending. The current shared prompt supports the single-line synthetic control contract, not general accounting. If rules differ, revise the contract before freezing. New clean model session, no historical conversation, memory or repository/gold access. Record actual model/version, prompt hash, tool policy, date, repeated runs and response traces. No API integration or model billing configured. No claim of blind performance on the existing public development suite.
3. Import model outputs as submission JSON per W001-EXP-001: exact suite_sha256, unique run_id, mode AI, configuration incl model_version, prompt_sha256, tool_policy, execution_date, outputs. Preserve raw responses separately, no manual repair after seeing gold. Missing or invalid responses count as ERROR in a fully enumerated submission with original trace. Human/hybrid requires real participants and separate timers/ledger. Repeated runs are distinct, do not pool as independent cases.
4. Score with python -m pipeline.model_comparison --cases /private/cases.json --gold /private/gold.json --submission /private/model-a.json --submission /private/model-b.json. Paired exact case counts (both correct, A only, B only, neither), false accepts, abstentions and issue accuracy. Descriptive results only; no inferential test or representativeness certified. Compare at equal operational safety and scope; no extrapolation to employment. Costs and times absent unless measured/documented.
5. Before release: review actual traces, reviewer independence, legal rights, leakage, case mix, error severity, full cost and uncertainty. A reviewer may deny progression. No automatic G-M1/G-M2 approval.

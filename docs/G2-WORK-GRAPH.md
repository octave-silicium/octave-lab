## Architecture et preuve
ADR-003 : graphe relationnel en mémoire, identités qualifiées par référentiel/version/type/code natif, relations many-to-many, source/table/ligne, manifeste SHA256 et date de collecte. Rejet des liens orphelins, clés dupliquées, schémas inattendus et nombres de lignes divergents. Répétitions hiérarchiques légitimes dédupliquées. Les tâches sans activité associée demeurent non mappées ; aucune imputation. Libellés anglais d'origine. Aucune donnée brute stockée dans GitHub ; collecte à la demande, rapport de métadonnées uniquement. La provenance permet d'identifier un fichier, pas de garantir sa reconstitution sans coffre. Les IDs sont stables à version identique ; pas de correspondance interversions présumée. Commande Python 3.11 : `python -m pipeline.work_graph` ; recherche `python -m pipeline.work_graph --search accountant` ; profil `python -m pipeline.work_graph --occupation 13-2011.00` (réseau nécessaire). Pas encore d'interface G2. 
## Limites
DWA est une activité détaillée normalisée, pas forcément une action atomique, une étape de processus ou une fréquence observée. Descriptions et liens source sont SOURCE_DOCUMENTED, non vérifiés en entreprise. Aucune note IA, aucune pondération, aucun processus, aucune estimation d'impact, aucun lien avec NACE/Indeed. G-M0 exige toujours ROME/ESCO, modèle d'action et processus, droits et mappings ; G-M1 exige vérification humaine et accord inter-évaluateurs. Tests synthétiques distincts de l'exécution sur les sources réelles.

# G1 v0.1 | Premier parcours vertical
Statut : implémenté, 140 tests Python réussis ; parcours navigateur à confirmer. Application locale interne (pas un site hébergé).
## Décisions BENCH-001 / ADR-001
FRED API (https://fred.stlouisfed.org/docs/api/fred/overview.html) : adopter séparation catalogue, série, source et paramètres exacts ; pas de prétention à ALFRED tant que le coffre n'existe pas. OWID Grapher (https://ourworldindata.org/redesigning-our-interactive-data-visualizations) : adopter changement graphique/tableau et provenance contextuelle ; différer partage/export. Harvard Atlas : référence à approfondir, accès direct à la page About non obtenu lors de cette revue ; ne pas prétendre auditer son architecture. Comparaison : serveur Python standard + JS natif/SVG, versus framework SPA + API/DB dédiée ; retenir le premier pour réduire dépendances, coûts et délai de preuve, réévaluer sur mesures réelles. Playwright limité aux tests navigateur, version épinglée. Aucun CDN.
## Démarrage
Depuis la racine du dépôt : Python 3.11+, `python -m pipeline.explorer`, puis http://127.0.0.1:8765 dans le navigateur. Quatre jeux archivés par défaut, sans téléchargement réseau. `python -m pipeline.explorer --live` ajoute les cinq jeux transitoires (réseau requis) ; non testé par le parcours navigateur initial. Serveur exclusivement loopback IPv4, Host exact, contrôle Sec-Fetch-Site, no-store, CSP, pas de CORS ni export. Ne pas exposer sur réseau, tunnel ou hébergement public ; pas d'authentification multi-utilisateur.
## Fonctionnalités
Catalogue, recherche de sources, filtres dépendants par combinaison native, choix d'une série exacte (max 100 propositions, affiner si nécessaire), période, points observés (axe zéro, pas de lignes entre points), détail de preuve, tableau paginé, clair/sombre, responsive, états d'erreur et zéro résultat. Valeurs WITHHELD/RESTRICTED masquées côté serveur. Pas de calcul de variation ni de comparateur, pas de public, partage, export, comptes ou sauvegarde de recherches. Garde-fous S1 inchangés.
## Recette
Tests Python sur archives réelles et fixture explicitement synthétique pour masquage. Tests Playwright : 1440,1280,768,390 px ; navigation source, graphique, tableau, période, preuve, pagination, thème, absence de débordement et d'erreurs JS, sécurité HTTP minimale. Captures prévues en CI, non publiées pour ne pas exposer les valeurs de l'interface interne. Le rapport de métadonnées seul est publié. Revue visuelle humaine, clavier complet, audit accessibilité, budgets p95/LCP/INP/CLS, robustesse réseau live et UX-G2/G3/G4 restent ouverts. Les temps initiaux CI ne sont pas des métriques terrain.
